# 08 — Owner Operating Guide (Genesis)

1. On Play+ FreePlay, open **Menu → Genesis**.
2. Select an **external MIDI** track with the select pads (tracks that are not `type==1 && inst==0` show *Not MIDI track* / *need MIDI*).
3. Top key cycles **Melody → Euclid → Arp**.
4. Shift+encoder chooses a parameter; encoder changes its value.
5. **Click** Generate (uses on-screen seed). **Shift+Click** Regenerate (new seed) then generate.
6. Preview shows occupied steps, notes, hit count, and seed. Pads mirror occupancy temporarily.
7. Bottom key while configuring shows **Apply in G3C** — Apply is not available yet.
8. Back from preview returns to edit; Back again leaves Genesis. Nothing is written to the sequencer.

Tips: keep Length ≤ the track’s pattern length (default 16). Identical seed + settings reproduce the same preview.
