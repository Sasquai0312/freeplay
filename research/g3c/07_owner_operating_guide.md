# 07 — Owner Operating Guide

1. Menu → **Genesis**.
2. Select an external MIDI track (select pads). Non-MIDI → *need MIDI* / *Not MIDI track*.
3. Top cycles Melody / Euclid / Arp. Shift+encoder = parameter; encoder = value.
4. Click = Generate; Shift+Click = Regenerate (new seed).
5. Preview shows steps. **Bottom = Apply** (EMPTY_ONLY).
6. If region occupied → *Replace? Apply again*. Bottom confirms REPLACE; Back cancels.
7. Success toast `Applied N tXX`. Notes are ordinary sequencer steps.
8. If **RECOVERY** appears: stop Apply; reboot / reload disposable project; do not rely on Undo.

Pattern length must be **16** steps for Apply. No physical MIDI claim in this phase.
